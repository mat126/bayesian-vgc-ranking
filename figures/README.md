# `figures/` — versioned

Plots generated by the analysis notebooks. Small, referenced from the README and blog, so
tracked.

| File | Content |
|---|---|
| `tau_blocks.png` | `tau` scale per block — the headline chart: player skill dwarfs team features |
| `ranking_species.png` | Species effects, top/bottom 20, credible intervals |
| `ranking_item.png` / `ranking_moves.png` | Item and move effects |
| `ranking_teams.png` | Top 15 teams by posterior strength |
| `calibration_nuts.png` | Held-out calibration: predicted probability vs observed frequency |

Forest plots show the posterior mean with the 5-95% interval and a dashed line at zero; **red**
marks effects whose interval clears zero, **grey** those compatible with zero. The calibration
curve bins held-out predictions by decile — points on the diagonal mean well-calibrated
probabilities, which matters more than accuracy for a model meant to express uncertainty.
